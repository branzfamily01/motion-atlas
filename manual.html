Motion Atlasは、Webページの「動き」を目で見ながら選ぶアプリです。名前を知らないアニメーションでも、実際に動かして比較し、AIへの指示文やHTML/CSSとしてコピーできます。

② まずこれだけ

1動きを見る一覧のカードを見ます。右下の ↻ で何度でも再生できます。
2「調整する」を押すSpeedやIntensityを変えて、自分がほしい動きに近づけます。
3AIへ渡すAIへの指示をコピーを押し、ChatGPTなどに貼り付けます。

① このアプリは何をするもの？

WebアプリやWebページに使うアニメーションを、コードの名前を知らなくても目で探せる道具です。

「ふわっと出したい」「高級感がほしい」「完了を分かりやすくしたい」のような感覚から探せます。

④ 使い方

A. まず動きを探す

  1. 一覧を見ます。
  2. 気になるカードの右下にある ↻ を押します。
  3. もっと詳しく見るなら 調整する を押します。

B. 動きを調整する

  1. ↻ Restart で再生します。
  2. Speed で速さを変えます。
  3. Delay で始まるまでの待ち時間を変えます。
  4. Intensity で動きの強さを変えます。
  5. Easing で加速・減速の感触を変えます。

C. AIへ渡す

  1. 好みの状態にします。
  2. AIへの指示をコピー を押します。
  3. ChatGPTなどの入力欄へ貼り付けます。
自分でWebページに貼りたい場合は HTML / CSSをコピー を使います。

D. いくつかを比べる

  1. カードの ＋ 比較 を押します。最大4つです。
  2. 画面下の 比較する、または上部の Compare を押します。
  3. ▶ Sync Play を押すと、選んだMotionが同時に再生されます。

⑥ データについて

お気に入りなどは、このスマホ・PCのブラウザの中に保存します。

  • 保存される：お気に入り、比較中のMotion、PREVIEW TEXT。
  • 保存されない：Speed / Delay / Intensity / Easingの詳細調整値。Motionを開き直すと初期値に戻ります。
  • ページを再読み込みしても、保存対象は残ります。
  • 別のスマホやPCには自動で移りません。
  • ブラウザのサイトデータを削除すると、お気に入り等も消えます。
詳しく知りたい人向け

保存にはブラウザの localStorage を使っています。アカウントや外部データベースへ送信する仕組みはありません。

⑦ 間違えたとき

  • お気に入りを間違えた → ★をもう一度押すと外せます。
  • 比較に入れたものを外したい → ✓ 比較中 をもう一度押すか、比較画面の 削除 を押します。
  • 比較を全部消したい → 画面下の クリア を押します。
  • 検索で何も出なくなった → 条件をリセット を押します。
  • 調整をやり直したい → 詳細画面を閉じて、もう一度 調整する を押します。

⑧ 困ったとき

動きが見えない / 再生が終わっている

↻ または ↻ Restart を押してください。端末の「視差効果を減らす」「モーションを減らす」設定によっては、一部の動きが控えめになります。

「Compare」を押しても開かない

先にカードの ＋ 比較 を1つ以上押してください。比較は最大4つです。

コピーできない

ブラウザのクリップボード権限が使えない場合でも、アプリは別のコピー方法を試します。それでも難しい場合はSafari/Chromeで開き直してください。

前のお気に入りが消えた

別の端末・別のブラウザを使っていないか確認してください。ブラウザの履歴・サイトデータを消した場合は復元できません。

オフラインで初めて開けない

最初の1回はオンラインでアプリを開く必要があります。その後、必要ファイルが端末に保存されます。

⑨ スマホで使う方法

iPhoneのホーム画面に追加

  1. SafariでMotion Atlasを開きます。
  2. 共有ボタンを押します。
  3. 「ホーム画面に追加」を選びます。
  4. 追加後は、普通のアプリのようにアイコンから開けます。
ホーム画面に追加する前に、一度オンラインでアプリと「？ 使い方」を開いておくと、通信できない場所でも確認しやすくなります。
